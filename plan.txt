Create a wails3 application that will rename files and directories. The 
application will contain two windows, a main window and a setup window.

The main window will have a toolbar across the top of the window and below 
it will be a grid control using the tabulator control.

The toolbar will contain the following items: Load, Save, Record, Play, Play All, Setup. each item will have an 24x24 
pixel icon and the name. The first five are left justified and the Setup button is right justified.

The grid will contain the following columns: name, date created, date modified, size, 
original_name. The grid will fill the remainder of the window and will expand and contract
as the window size changes. Only the name column will vary in width and will expand so the 
entire row of columns will take up the full width of the window.

The name column is editable, the others are read-only. The original_name column is hidden.
The grid can be sorted by any of the visible columns.

The Load button will load the filenames and directories from the filesystem. When the button
is pressed, a system dialog will open that will allow the user to select a directory. 
when the 
directory is selected. the contents of that directory will be placed into an array that will be
loaded into the grid. name and original name will contain the name of the file/directory. 
the dates and sizes are also matched. The grid can also be filled using drag-and-drop.  
if a directory is dropped on the grid, all files and dirs in that directory will 
populated the grid. if a group of files/dirs is dropped, then only those files/dirs will
be loaded into the grid.

The save button the update the filename or directory in the filesystem if the name and 
original_name columns are different (the name field has been edited). it will loop through 
all the rows in the grid renaming the corresponding filename/directory.

The record button will allow the program to save the keystrokes (including home, 
end, left arrow, righ arrow, etc) when performing an edit on the name column.
it will also save the starting position (offset) to the cursor when starting 
the record. Pressing the up or down arrow, the enter key or the record button again 
will stop the recording.

The play button playback the keystrokes starting from the saved starting position in the row 
of the grid in the name column. 
This will perform the same edits that where done when the macro was recorded.

Play All button will perform the edit on all rows except the current row.  If a number of 
rows are highlighted (selected) then only those rows will be affected.

The setup button will open a new window called Setup. It will contain a field called Dark Mode 
with a checkbox. when this is ticked, the application will be in dark mode using shades of grey.
otherwise it is light mode, using shades of grey.

Note: the frontend javascript will only contain code to manage the frontend. All filebased 
activity will be done in the go backend.
